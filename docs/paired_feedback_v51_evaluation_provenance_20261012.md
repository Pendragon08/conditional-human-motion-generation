# V51指标来源补充说明

此说明在独立审计指出原始跟踪指标的合成参考标注不足后追加。原始文件、分数、判据和运行代码不改写；审计发现保留。补充说明不能证明此前记录已充分标注，也不能将模拟结果转化为真实机器人证据。

## 三类评价对象

- **条件误差**：目标由HumanML3D来源动作和预先规定的水平偏移构建，在候选生成前冻结。候选输出不能重新定义原始位置、朝向或目标时刻。它评价候选对指定条件的满足程度，不将生成轨迹本身作为目标位置真值。
- **跟踪误差（synthetic_proxy）**：初次构建比较实际模拟状态与生成器提供的参考；筛选后的独立回放比较实际状态与此前候选的物理模拟轨迹。后者是合成、物理精化的参考，不是真实MoCap执行轨迹或真实机器人真值。跟踪误差反映固定控制器对该参考的保真度，不能单独证明动作语义正确、物理可执行性或下游训练价值。
- **物理质量（simulation_only，含代理）**：穿透及连续性依据保存的模拟状态计算；足部滑移是受力支撑和碰撞几何表面的速度代理，不能称为真实脚滑或真实接触点真值。解析控制校验不认证实际人体所有接触状态。

“联合合格”是冻结条件判据、模拟物理质量代理、完整执行及合成参考跟踪判据的合取。它在本轮是模拟诊断指标，不是获得认证的机器人可执行性。必须区分构建与回放；构建失败后的补齐轨迹不能仅凭回放完成恢复端到端成功资格。全部216输入每方法均保留在分母。

V53只读分析会显式保存上述评价来源，并绑定原始指标、选取记录及本说明的哈希。V51原始跟踪字段和 `source_type=physics_refined` 不追加修改；标注不足的历史发现由独立审计记录。新分析只覆盖24验证来源、3种偏移、3生成种子，没有独立测试、G1实验或下游训练收益证据。不能以小的合成参考跟踪误差宣布创新有效。
