# 初始化坐标测量复核（独立修订，不与旧实验合并）

旧轮参考及目标使用角色创建时的坐标，而实际角色随后经过重置。
因此旧轮不是受控的绝对目标偏移或纯生成种子重复实验。
本复核先重置环境，再构造参考与目标；环境种子固定为11，生成种子为11/12/13。
不改变冻结模型、跟踪器、动作质量阈值、语义条件、原目标或反馈更新规则。
不把根节点对齐等同于完整关节初态匹配。

每批最多600秒；时间单独登记，并与旧轮总账合并检查72 GPU小时、
测量4 GPU小时、数据盘20GiB与总新增输出15GiB上限。

## 校验

- 第一控制步前记录实际、参考和重置时的根位置；XY误差必须小于1mm。
- 比较三个种子时目标及参考应相同，生成噪声应不同。
- 同一来源三个偏移案例的目标差必须是预定的±15cm，不能加入不同随机平移。
- 同一案例跨模式的原目标、前缀输入与时间索引必须可追溯。
- 脚本成功运行不代表测量与动作质量通过；保存独立复核结论。
- 如果初始化修复未通过或验收仍无法区分物理合格动作，停止后续G1和下游训练。
  不根据已见测试结果放宽物理阈值，不将修订复核与旧成绩混合。
