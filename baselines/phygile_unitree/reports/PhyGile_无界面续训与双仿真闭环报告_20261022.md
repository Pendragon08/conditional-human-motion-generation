## 双仿真闭环迁移

| 验证项 | Unitree RL Lab / PhysX | Unitree RL Mjlab / MuJoCo-Warp |
|---|---|---|
| 实际物理执行 | 7 个独立子进程，均退出 0 | 实际 CPU 物理场景，主进程退出 0 |
| 恢复方式 | 新进程重建同种子场景、回放已接受历史 | 新场景重建、回放已接受历史 |
| 重复执行与历史回放差值 | 0 | 0 |
| 反馈正向工程夹具 | 2 个被接受的 1 帧窗口 | 2 个被接受的 1 帧窗口 |
| 真实扩散候选 | 2 次 50 帧候选均被拒绝 | 2 次 50 帧候选均在 1 帧后失败并被拒绝 |
| 生成帧提交数 | 0 | 0 |
| 已训练语义动作生成 | 未验证 | 未验证 |

正向夹具的目标是“保持初始化姿态”，明确属于自监督代理测试，不能当作数据集真值或学习生成效果。真正候选来自未训练扩散模型；两边均保留失败、终止和拒绝原因，不将无效片段拼入已提交前缀。执行采样时序为物理推进后、自动复位前，候选期间不进行自动复位。FK 目标来自候选关节/根状态，没有用实际机器人输出替代目标。

PhysX 没有宣称能完整序列化私有求解器状态，因此使用新进程回放。MuJoCo 路径同样使用重建场景回放，并逐段检查已接受历史误差不超过 2e-6。当前证据是同种子、初始化附近的有限工程验证，不代表任意动作和长历史的完全恢复保证。
