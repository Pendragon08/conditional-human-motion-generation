# PhyGile：Unitree RL Lab 适配与 Unitree RL Mjlab 跨仿真报告

日期：2026-10-22。本文记录自行实现的 G1 跟踪器框架迁移，不是论文官方迁移实现。

## 当前结论

Unitree RL Lab 自定义任务已真实加载原 PhyGile 检查点、MoE 与经验归一化，原生图形窗口完成 100 次策略控制；随后在四个测试片段上完成冻结策略评估。Unitree RL Mjlab 也已通过真实 MuJoCo-Warp 步进、官方 G1 任务执行与独立文档见证。

同一策略在 Isaac 路线完整完成 **2/4** 个片段，在 MuJoCo 路线完成 **1/4**。初始输入和策略输出已数值核验，但跨仿真动作稳定性不足。本次结果支持“接口已接通，并测得迁移退化”，不能支持“两个引擎效果一致”或“已达到论文性能”。

**新 PPO 续训没有启动，也没有生成新训练权重。** 项目既有 AGENTS.md 要求先验证服务器 GUI、GPU 渲染和用户本地连接；前两项已经验证。用户回复“暂时无法查看”，因此本地连接仍未确认。已准备训练分支，但不会将冻结推理当成训练完成。

## 2. 适配内容与参数对齐

1. `PhyGileUnitreeEnvCfg` 继承 Unitree 官方 G1 mimic 环境，携带原 PhyGile 场景、指令、观测、奖励、终止条件和算法扩展。实际运行时与原配置进行语义比较并通过；评估时的确定性覆盖另行记录。
2. 保留原 616D actor 输入、748D critic 输入、29D 动作、MoEActorCritic、MoEPPO 与归一化状态。父策略仅激活 1 个专家（分配 12 个），不是完整论文 MoE 训练结果。
3. 两套关节顺序按名称显式置换，保持原策略顺序。520D 运动指令由当前帧、即时未来帧 1/2 和编码器未来帧 1/21/41/61/81 组成；每帧 65D。
4. 其余输入是相对锚点方向 6D、机体角速度 3D、相对默认关节角 29D、关节速度 29D、上一动作 29D。四个片段的初始 520D 指令完全一致，其余初始观测的最大差异小于 0.000001。
5. 统一物理步长 0.005s、decimation=4、控制周期 0.02s（50Hz）；动作缩放/偏置通过实际运行断言。29 个关节的已编译刚度、阻尼、力矩上限和 armature 与原完整精度契约逐项相等，见 `mjlab_compiled_dynamics_v1.json`。
6. Mjlab 保留其官方 G1 模型和求解器。资产不是逐项等同：例如骨盆质量 Isaac 约 3.814kg、Mjlab 3.813kg，躯干约 7.817kg 与 7.818kg；几何、接触及求解器仍有差别。不能把全部退化归因于某一个差异，尚未进行归因消融。

## 3. 检查点与数值验证

父检查点：`model_1999.pt`，67,349,356 bytes。
SHA256：`bb067f364de74e2da7cf1879e6f26bb961a71eb9ff64cbfbe84dd858bfae2336`。
它来自此前 2000 次 PPO 迭代的 pilot；一次 PPO 迭代包含 20 次 Adam 步，不能将二者混称。

策略权重与两套归一化统计在 Isaac 加载后逐张量精确核验。便携推理保持原 MoE 源码及原 RSL 归一化公式 `(x-mean)/(std+0.01)`。

初始合成夹具对比曾在 0.00001 固定容差下失败（最大动作误差约 0.000592）；没有放宽容差。补充的原运行时 CPU、关闭 TF32 的 GPU 及便携 CPU 对照通过：两组各五条合成输入的最大误差约 0.00000215，归一化输入差异为零。开启 TF32 可重现此前 GPU 夹具（与原夹具误差约 0.00000119），因此后续冻结评估明确关闭 TF32。

进一步对八次真实评估的初始观测检查：Isaac GPU 与便携 CPU 最大动作误差约 0.000000328，Mjlab CPU 路线为零；全部通过相同容差。合成输入的数值验证只说明加载/计算一致，不构成动作质量指标。证据为 `frozen_policy_parity_v3.json` 与 `crosssim_summary.json`。

## 4. 实验协议与结果

使用原工程保留的四个测试片段，每段 149 帧、2.98s；每个引擎每段只运行一个确定性 episode，seed=2026。两套引擎逐片段的原动作文件 SHA256 相同。

从第 0 帧开始；关闭观测噪声、启动材质/默认角/COM 随机化、推扰及复位姿态/速度扰动。该协议与此前含随机扰动的 pilot 不同，不能直接混用表格。保留原失败终止阈值：锚点高度差 0.25m、重力投影差 0.8、四个末端高度差 0.25m。

在物理推进后、自动重置前，相对当前指令帧 t 采样，第一次终止即停止。为对齐测量时刻，Mjlab 在终止检查前显式 forward 更新派生运动学；这是评估覆盖，已记录。MPJPE 为 14 个跟踪身体位置的原始米制欧氏误差；关节角/速度为 29 个关节的绝对误差均值。参考来自数据集运动学数组，未从策略输出生成。

## 5. 独立见证、失败记录及保留情况

独立代理按文档逐字运行带种子的 Torch 反向传播/真实 MuJoCo-Warp 两步探针，再运行实际 Unitree G1 三次控制（十二步物理）；两条命令均退出 0，动作契约精确、优化步数为零。见 `results/v1/doc_witness_report_v1/REPORT.md`。见证只覆盖有限 CPU 探针，不表示完整动作成功、服务器训练就绪或用户本地 GUI 已验证。

开发失败没有覆盖或删除：首次 Isaac 冷启动很慢，达到 GUI_READY 后由本次任务停止自己的预览进程，不能当成正常完成；GPU1 直接呈现 Xorg 窗口发生 Vulkan 失败；后续改为 GPU0 渲染。Mjlab 缺少 SciPy、中文 XML 路径失败、一次 list/tuple 顺序断言失败，以及原始 TF32 夹具失败记录均保留。

服务器保留原 20 个训练片段、4 个测试片段及父检查点；最终哈希未变。原始动作、包含参考数组的逐步状态和人体模型资产存放在授权的本地/服务器目录，受许可限制不上传公开 GitHub。GitHub 保存来源索引、哈希、代码、执行记录、纯合成夹具、逐片段指标及报告。原始结果可根据 `private_raw_manifest.json` 在本机核验。

ReactiveBFM 未停止、重启、修改官方规划器/跟踪器基线或共享依赖。最后只读检查时间：2026-10-22T09:51:42.847263+00:00；两卡有效优化更新分别为 11034,11034，跳过次数均为零，参数/梯度与 EMA 验证正常。记录见 `monitor_final.json`，不表示其完整训练已经结束。
