# PhyGile 与 ReactiveBFM 论文复现进展报告

更新时间：2026-10-23（北京时间）；训练状态采样 UTC：2026-10-22T16:13:20.059820+00:00。

**两篇论文均尚未完成论文级性能复现。** 本轮完成论文与官方代码对照、PhyGile 大网络参数配置、ReactiveBFM 异步闭环修复，以及真实仿真执行记录的视频。ReactiveBFM 全量步数训练仍在继续。报告不把短程测试、未训练生成器或站稳不倒当作完整复现。

## 1. 复现依据与范围

PhyGile 使用[原文 v3](https://arxiv.org/pdf/2603.19305v3)和[官方跟踪仓库固定版本](https://github.com/Baojch/phygile_tracking/tree/d48621620f522f5c901ef378d57db8df92d2888d)。官方发布范围是 Tracking；生成器及 physics-prefix 部分现有工程属于自行实现，须单独验证。

ReactiveBFM 使用[原文](https://arxiv.org/pdf/2606.30362)和[官方代码固定版本](https://github.com/zjwzcx/ReactiveBFM/tree/5a79d03cab824eb5917271ba720294e8a1b9d374)。保留官方规划器、训练目标和冻结的 ScaleBFM M 跟踪权重。论文附录 B1 明确不对下游控制器微调；控制器 PPO 表描述其预训练，不能误当作本次必须重训的一个阶段。

两条主线优先官方算法；Unitree 框架适配结果作为补充迁移诊断。全部为仿真，无真机部署。

## 3. ReactiveBFM 训练与参数差异

两个训练进程均为 TRAINING，有效优化更新 **14,077/1,000,000（1.41%）**，跳过次数0，EMA及参数有限性检查通过。采用2卡×512，总batch1024、LR1e-4、400000步教师强制预热、之后渐进自回归至1000000步。当前尚未进入自回归训练阶段。

公开 README 采用8卡×128和400k/1M日程；本次保留相同全局batch，改用两张共享A6000。为修复数值异常使用FP32和激活重算，是已记录的执行差异。恢复保留模型、EMA和Adam状态，但历史随机数/数据顺序不保证逐位复现。

当前恢复段平均约7.49秒/更新。仅作资源估算，若速度不变，剩余步数约需85.4天；不是完成时间承诺，也不等于论文报告的单卡48小时。不能把完整训练说成已结束。

| 对照项 | 原文/官方资料 | 当前差异 |
|---|---|---|
| 规划器训练表 | 原文表4列Adam、128batch、2500iterations，同时列PPO式参数 | 与公开flow matching训练程序不一致；本次按公开训练代码执行并保留冲突 |
| 历史/未来窗口 | 原文部署20/40帧 | 发布代码/当前训练检查点为25/50帧，尚未做严格20/40训练对照 |

## 4. ReactiveBFM 异步闭环修复与实测

此前固定applied_frame=10会进入官方串行应用分支。本轮改为applied_frame=0、真实观测前缀、缓冲阈值10帧和官方5帧融合，进入异步规划路径。首次未加速测试虽完成500次控制，但大量结果过期；这些失败记录保留。

官方torch.compile在当前Torch2.5环境遇到CUDA Graph复用输出/文本KV缓存的问题。修复在独立兼容层中完成：保留官方模型与采样数学运算，克隆CFG输出、关闭Graph重放而保留Inductor编译。实际首次CFG与未编译结果最大差为6.68e-6，通过固定容差检查；不修改运行中的训练源码。

[查看实际闭环执行视频](https://github.com/Pendragon08/conditional-human-motion-generation/releases/download/paper-reproduction-progress-20261023/ReactiveBFM_actual_async_10041updates.mp4)。这是10,041次更新的早期检查点，提示词“walk forward”、seed42，500次真实控制调用，10秒仿真时间，20次规划被控制器实际采用。视频按仿真50fps播放，不能用于证明50Hz墙钟实时性能。

采用论文的高度≤0.3m、单帧相对MPJPE≥0.1m或xy漂移≥3m阈值，但身体集合明确选为骨盆+29关节子刚体；作者身体集合未公开，因此是透明的近似诊断。所有500帧均参与统计，没有只保留成功前缀。首次违规为从0计数的第9帧。不存在跌倒并不等于跟踪成功，也未对语言语义作合格判定。

独立按文档复跑：200次物理控制、7次新规划被采用；119个源码哈希及检查点不变，所有已保存数值数组有限。训练两卡在复跑期间13975→13982，未被中断。文档原有一处跨分支文件链接错误，已修正并保留修正时间记录。
