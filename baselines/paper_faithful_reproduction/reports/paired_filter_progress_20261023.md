## 本轮真实物理执行

复用固定的官方ScaleBFM M检查点及原生PyTorch兼容层，仅CPU四线程执行，GPU不可见；没有修改ReactiveBFM的规划器、跟踪器、环境或训练。检查点SHA256：`88d5a79946c03ed25503f48b2af71d16290844ef066ca9b6c8fa8dc3837422e3`。该跟踪器作为外部辅助筛选，**不等于PhyGile论文Stage-II训练后的GMT**。

执行链路为：冻结40条时钟一致262D特征与侧文件哈希 → 解码G1世界根位姿/29关节 → 固定20→50Hz时间网格插值 → 按关节名称映射 → 首帧位姿和速度初始化 → 真实MuJoCo控制 → 保存每个pre-reset状态与失败项。控制周期0.02秒，物理子步0.005秒；关闭根位姿强制跟随，无自动重置、无时移拟合、无动作时长拉伸。每条在首个终止条件触发时停止；失败前均值受截断影响，不能视作整段质量。

使用的三个终止判据来自论文跟踪评价：骨盆高度误差0.3m、躯干重力投影差0.8、四个指定手脚末端高度最大误差0.3m。完整片段平均绝对MPJPE小于0.1m是**另加的独立实现选择**，不是作者公开的数据过滤阈值。当前30刚体名称集合和外部控制器也未与作者过滤逐项确认，因此不进行论文同口径成功率比较。

## 测量时序修复及复核

首次视频核验发现新记录器在读取积分后的qpos时，MuJoCo的派生刚体位置仍对应前一个0.005秒子步，最大可视FK差超过2毫米。旧批次20/40通过结果被标记为历史结果，首版渲染失败回执及全部原始轨迹保留。

修复只在独立MjData中复制当前qpos，调用`mj_kinematics`重算同一时刻的刚体位置与躯干朝向，**不修改实时仿真的状态、控制输入或求解器**。随后在同一检查点、种子、阈值和数据上重跑全部120回合。新旧每条共同执行区间，共10,962个控制帧，qpos与动作逐位一致；改变的是测量值和据此决定的终止位置。修正后32条整段执行、21条通过，不把旧20/40与新21/40解释为策略性能提升。该时序机制依据[MuJoCo计算流程官方文档](https://github.com/google-deepmind/mujoco/blob/main/doc/computation/index.rst)。

本轮另外核查既有ReactiveBFM离线分析器：它从保存的实际状态重算FK，不使用本次有误的旧派生位置，因此没有据此改写先前闭环指标。

独立阅读者按[冻结命令](../PAIR_FILTER_INVOCATION.md)原样执行一次，退出0；123/123控制调用，整段平均MPJPE52.47mm，输入、源码和权重哈希未变。见证期间ReactiveBFM从11,382继续到11,383次有效更新。该见证只证明有界实际执行与文档可运行。

## 为什么尚未启动完整生成器

当前只有小规模辅助候选集，不能替代论文约45小时语料、真正GMT过滤和课程。已公开[PhyGile仓库](https://github.com/Baojch/phygile_tracking)主要提供tracking，未提供完整生成器训练工程；独立生成器实现与公开网络参数已对齐并单独记录来源，但作者未公开的内容仍有独立选择。

| 阶段 | 当前状态与阻塞 |
|---|---|
| 原始配对语料 | 缺原生16beta SMPL+H模型、其余索引对应动作及可靠片段核对；本轮新增配对0条 |
| 论文GMT Stage I/II | `[2048,1024,512]`、12专家等已配置；未训练完，不使用旧2,500步小网络冒充；8192环境尚未在共享GPU资源下验证 |
| 论文物理过滤 | 新完成外部ScaleBFM辅助筛选；原生GMT过滤尚缺训练权重 |
| 课程与ASFO | 作者难度CSV未公开；完整真实标签、ASFO与镜像训练准备尚未完成 |
| 完整生成器训练 | 未启动；没有合格validation集和充分语料，新真实生成器优化步0 |
| 生成—执行—反馈 | 时钟与codec接口验证已完成；训练后生成闭环及生成分布PPO尚未执行 |
| 正式评价 | 私有3小时数据、作者评价权重/划分等不可公开获取；不能声称完全一致 |

论文公开的生成器网络为8层Transformer、宽512、FF1024、4头、12个时间专家、dropout0.1，冻结768维DistilBERT；条件丢弃0.1、负载均衡权重0.01、CFG2.5等按固定论文核对。优化器/学习率计划、batch与训练步数、去噪日程、精确codec差分、部分ASFO和闭环PPO参数未完整公开，不能将现有示例值说成原文值。完整缺口及已知配置保存在`paper_training_readiness.json`，依据仍为[固定PhyGile v3论文](https://arxiv.org/abs/2603.19305v3)和既有参数核对清单。
