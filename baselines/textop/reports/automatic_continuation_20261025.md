# TextOp 自动接续执行安排

用户已明确授权：数据准备和真实物理筛选完成后，直接开始完整训练和闭环验证。

执行顺序：可用数据准备与备份 → 特权策略及宽松、严格两轮物理筛选 → 最终语料、训练集归一化、CLIP缓存和运行条件验收 → 新69D VAE20万步 → LDM30万步 → 所需最终全身控制器与生成运动增强 → 实际仿真闭环、失败案例和执行视频。

数据验收通过后自动启用训练配置并接续下一阶段；阶段完成通知与执行并行，不作为确认等待。当前训练开关保留数据验收条件，不能把仅完成重定向、参考导出或短诊断当成验收通过。

继续使用服务器GPU1、CPU4、Torch显存比例0.65及无界面模式；保护数据集、检查点、实验记录和其他用户目录。PhyGile、ReactiveBFM与旧57D训练继续暂停。代码、聚合结果、可公开视频和报告同步GitHub及本地，受限原始与逐条文本资产保持私有。
