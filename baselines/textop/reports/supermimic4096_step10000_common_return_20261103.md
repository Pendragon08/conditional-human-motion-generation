# 旧 SuperMimic 4096 环境策略：第 10000 次采样迭代统一回报

2026-11-03 完成一次固定检查点评估及独立审核。此记录属于旧版 SuperMimic 后继实验，与新版 Vibed 的 4000 次优化实验分开。

## 同口径结果

在同一批 **564 条生成参考**上，采用 **14 身体、六项跟踪统一回报**：

| 策略 | 序列等权平均统一回报 |
| --- | ---: |
| PPO 第 5000 轮，历史已审 | 0.1891144878 |
| 旧 SuperMimic 4096 环境，第 5000 次采样迭代，历史已审 | 0.1708874747 |
| 旧 SuperMimic 4096 环境，第 10000 次采样迭代，本次已审 | **0.1789038691** |

本次比旧 Super5000 高 **0.0080163944**，仍比 PPO5000 低 **0.0102106187**。这些是描述性比较，不证明统计显著、等预算优势或同质量训练加速。第 10000 次采样迭代的检查点记录 num_updates=3984，不能与新版优化迭代直接等同。

全部 564 条均已评价并保留分母；其中 **57 条到参考末尾，482 条因根高度偏差、25 条因倾斜偏差提前终止**。本协议在失败区间及之后未执行的区间计零，并按每条完整参考的 N−1 个控制间隔计算；共 58,110 个预期区间，实际观察 8,999 个。六条两帧参考仍各占一条序列和一个预期控制间隔。

## 审核做了什么

- 核对全部参考与保存轨迹的 SHA-256、ZIP CRC、形状、有限值及初始状态。
- 对 **58,674 个参考帧**重建 14 身体 FK；这不表示全部机器人轨迹都执行了完整参考时长。
- 重放实际记录的 **89,990 个物理子步**，独立检查 PD、动作到关节目标映射、qpos/qvel、身体位姿和基于 Jacobian 的速度。
- 用旋转矩阵独立重算六项回报、提前终止及固定分母。汇总与生产结果完全一致；单序列最大分差约 6.66e−16。
- 动态重放 qpos/qvel 与 PD 的最大误差为 0；参考 FK 最大位置差约 6.92e−6 米。没有重新推理策略动作，也没有独立微分重算参考速度。

生产评估与审核均实际正常退出、子进程已回收。审核使用 CPU2、低 CPU/IO 优先级及共同锁；原受保护任务身份和状态检查通过。生产评估约 145.2 秒，审核约 30.4 秒，均不属于训练时间。

## 条件与解释边界

共同 GMR G1 模型、50 Hz 控制、0.002 秒 ×10 物理子步、固定 PD、参考首帧姿态和零初速度。推理采用独立 CPU 环境 Torch2.11 / NumPy2.5.1 / MuJoCo3.16，区别于旧训练及部分历史推理环境；22 条保存动作和20个记录物理子步的迁移见证只支持局部兼容性。

参考是文字条件生成代理数据，分类为 **synthetic_proxy + simulation_only**。它不是动作捕捉真实真值、论文 SnapMoGen 同条件测试或实机结果。三个种子属于参考生成，不是三个独立训练种子。

**这个统一回报不是 30 身体根相对 0.3 米成功率。** 不更新或替代既往 PPO202/564、Super4096第5000次201/564、新Vibed194/564等另一协议的结果。本次未训练新策略、未生成新视频、未上传新的模型权重。
