# DreamControl-v2：29DoF 四任务仿真改编复现

本目录保存 Pick、Pour、双手搬箱、推拉箱四项实验的实现、结果和审计证据。它是依据论文及公开 DreamControl 代码实现的 **29DoF 改编基线**，不是作者未公开 v2 实现的逐字复现，也没有达到论文性能。仅进行物理仿真，不包含真机实验。

最近执行记录见 [STATUS.md](STATUS.md)，既定任务和限制见 [PLAN.md](PLAN.md)。文件顶部新记录优先；历史记录和失败尝试保留。最初的工作区说明另存为 [初始 README](reports/README_initial_20261029_preserved.md)。

## 生成参考的质量与审计

采用公开 HumanML3D 评估网络和指标函数，项目的 586 条留出特征作为参考分布。最终参考整体 FID 4.3705，R@1/2/3 为 20.25%/38.75%/46.05%，Diversity 1.3768，Control L2 为 0.02991 m，Skating Ratio 为 0%。配对原始扩散输出分别为 1.4175、26.90%/40.60%/46.20%、1.3325、0.33411 m、7.32%。

这些值与论文 Full-Mix 的数据、条件分布和文本检索协议不同，不能直接作为同口径复现成绩。后优化降低空间误差但显著改变动作特征分布；0% 几何脚滑也不等于自然动作或物理抓持成功。[完整结果与边界](reports/generated_reference_evaluation_20261105/summary.md)。

训练、条件坐标、空间引导、后优化和评估适配的逐项审计见 [实验审计](reports/diffusion_pipeline_audit_20261105/EXPERIMENT_AUDIT.md)。用户已授权四项修复：统一正逆坐标和高度基准、修正空间引导与条件覆盖、限制后优化形变、明确分阶段与分筛选口径的评估协议。新版本拟先训练 10,000 次更新，再生成四类各 500 条新参考；本次发布时尚在代码与验收准备阶段，没有新的正式训练或质量结果。未完成的 `repair_prior29_v2_20261105` 开发目录暂不纳入代码发布。原模型、参考与失败结果全部保留。10,000 是本项目选择的训练更新预算，不是论文公开的训练步数，也不是 1,000 个 DDPM 时间步。

## 文件与恢复

`src/` 和 `tests/` 保留适配源码及诊断代码；部分文件属于历史尝试，运行前应以 PLAN/STATUS 和源绑定收据确认有效入口。GitHub Release 仍为草稿：八个服务器归档及 Pour 补充已核验，共有 **137/275 个检查点可以从完整上传组恢复**；另 **138 个本机冷档检查点的分块上传未齐**，不能称全部权重已上传。四个纠正手指显示的视频已经上传。发布清单记录原路径、归档成员、字节数及 SHA-256，最新覆盖状态见 [附件目录](publication/ARTIFACT_CATALOG.md)，恢复方式见 [恢复说明](reports/PUBLICATION_RESTORE_20261105.md)。附件必须按清单校验后使用；保留所有下载分块，恢复工具无需先在磁盘拼出大型 TAR。

归档中原始失败、早期原型及错误视频仍是历史证据，不能用它们替代最终结果。旧视频遗漏了手指计划；新版采用公开 DreamControl 的 Viser 播放逻辑、29 身体加 14 手指的输入适配。参考视频是运动学回放，不是策略执行或物体动力学成功演示。
