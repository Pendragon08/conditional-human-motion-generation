# 原 DreamControl 可视化代码重导出的四类参考动作视频

日期：2026-11-05。视频内容是既有后优化参考的运动学回放，未重新生成、拟合或训练，也不是物体交互成功演示。

## 使用的原代码与必要适配

机器人根位姿与关节动画使用 [DreamControl 固定版本的 visualize_trajectories.py](https://github.com/GenRobo/DreamControl/blob/ec28b508313d6837de52c68247fbc8cf81fe4935/TrajGen/sample/visualize_trajectories.py)，保留其 ViserUrdf.update_cfg 与根部位姿处理。原源码在本目录，完整 SHA-256 为 `b3bafd6202fe0337d05316c6759218c1b1baea0c8a02ecdd68b2c7501968ccea`。

由于当前参考是 29 身体关节加独立双手计划，而原入口默认 27 关节，输入适配器按关节名加入原仓库的 14 个手指关节，将 hand_closed 映射成项目现有开/合指令。29 身体关节和根轨迹保持原样；660 个源状态的手腕、脚踝 FK 矩阵与原身体 URDF 的最大差均为 0。原播放器自带的根部 +0.035 m 显示补偿已在输入端抵消，避免重复抬高。

实际三维渲染使用 Viser 随包提供、未修改的网页前端。通过 Viser 原生离线序列化接口保存动画，再用浏览器原生 MediaRecorder 录制两个视角；额外代码只负责输入适配、离线导出、相机、字幕和视频封装。不能称所有代码完全零改动，也没有另写机器人渲染器。`viewer_adapter.diff` 保留入口的全部替换。

## 与旧视频的区别和结果边界

旧视频漏播独立的 hand_closed 计划，不能用来判断手部闭合后的外观。新视频显示这套计划，但**没有修复参考本身的手腕姿态、掌指接触几何或物体约束**。看见闭合手型不等于抓住物体；身体跟踪通过也不代表物体任务成功。

原可视化入口只回放机器人与地面，本视频同样没有物体接触动力学。它适合复现报告中的“生成参考动作与手部计划展示”，不能标为“成功抓取／倒水／搬箱／推拉执行”。原始参考、旧视频和失败导出尝试都保留。
