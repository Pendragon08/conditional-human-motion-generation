# Mixed 29-DoF dataset: source and scope record

This is a provenance record, not a legal opinion or blanket license grant.

- **GRAB source:** [GRAB license](https://grab.is.tue.mpg.de/license.html) states that use is limited to the purposes specified there, including non-commercial scientific research, education and artistic projects. Source terms and restrictions continue to matter for derivative materials. This records the document, not whether every derivative grant is established for this project.
- **DexWeave robot references:** [dataset card](https://huggingface.co/datasets/naichuan04/DexWeave) describes G1 references; the project uses fixed data revision `264cde93a2b3f502ded55fe4e5c05234a2bdefa2` and verifies file and original GRAB-member hashes. The data card does not state a data license. A software repository license is not automatically the dataset license; grant applicable to the derivative data remains unresolved.
- **GRAB captions:** [MotionHub dataset card](https://huggingface.co/datasets/ZeyuLing/MotionHub) labels the dataset license as `other` and instructs users to follow the original source dataset's restrictions. It currently describes 1,335 GRAB clips and 4,005 captions, and states that released subsets received visual and format review. This is the current card, not proof of the exact review procedures or of semantic accuracy for our fixed revision `c3f6c8eb8a4ba9e5ca521cdc0af9264756b66726` after robot retargeting and truncation. Data use grant beyond upstream restrictions remains to be established.
- **OmniRetarget robot references:** [dataset card](https://huggingface.co/datasets/omniretarget/OmniRetarget_Dataset) declares MIT, identifies `robot-object/` as derived from OMOMO and describes the 29-DoF format. The declaration and fixed archive hashes substantiate the published reference source but do not on their own resolve every upstream right.
- **OMOMO captions:** [author's OMOMO repository](https://github.com/lijiaman/omomo_release) provides `omomo_text_anno.zip` and declares an MIT license for the repository. The repository's license and a downloadable annotation archive should not be silently equated with a blanket license for all underlying OMOMO content.

The existing 3,161-sample mixed manifest binds source/member and text hashes, but links by naming and hashes alone do not prove the captions match the altered robot motion or a cropped 10-second window. Research-use scope, upstream rights and derivative-data terms must remain explicit in any accepted dataset.
