候选创新方案：面向物体交互的物理反馈闭环扩散规划

状态：讨论稿。用户要求先完成现有四任务，再讨论新增创新实验；本文件不构成已批准的实验计划，不加入当前训练队列，不修改当前模型、参考库、奖励或训练预算。研究范围仍限物理仿真。

建议主问题：在动作执行落后、物体偏移或接触失败时，如何根据真实执行状态，修复下一段运动的接触约束、空间目标和执行时序，使任务继续推进？

一、文献核对与可主张的边界

| 文献 | 已经实现的机制 | 对本项目的启发和边界 |
|---|---|---|
| PhyGile，Bao等，2026，arXiv v3 | 用跟踪器产生的可执行运动前缀约束生成；按1秒续段进行生成、仿真跟踪、筛选和前缀延伸；适配阶段保持扩散模型固定，微调GMT | 可执行前缀和生成—跟踪适配已有先例。论文没有给出足以复现的逐步前缀采样公式、在线生成延迟或硬件扩散重规划频率，不能把50Hz跟踪等同50Hz生成。公开项目链接的是跟踪代码。 |
| CLoSD，Tevet等，ICLR2025 | 实际模拟身体运动反馈给扩散规划器；文本、关节目标和朝向条件；固定规划器并在闭环中适配跟踪器；FSM组织任务 | 在线反馈、任务切换和滚动重规划已有先例。官方默认20帧历史、40帧未来、10步扩散；参考表示20Hz，默认执行2秒再规划，并非20Hz重规划。源码允许执行窗口短于预测窗口。 |
| ContactMimic，Li等，2026，预印本 | 在关键点外明确建模接触指令，训练接触跟随与接触可控性 | “加入接触标签”本身不能单独作为新贡献。 |
| Humanoid-DART，2026，作者仓库标注RA-L2026 | 生成机器人与物体轨迹，跟踪验证，按实际达到目标重标记，扩展轨迹库并交替训练生成器和跟踪器 | “用执行结果回灌数据、再训练扩散”也已有工作。需要区分离线数据自举与部署过程中持续修复约束的在线机制。 |

因此，候选贡献不写成“首次实现扩散与控制闭环”。更具体的研究假设是：在同一机器人—物体任务中，将实际接触状态用于约束修复和时序调整，能够比仅反馈身体运动的闭环更好地保持抓持、处理接触失败并完成任务。此为待验证假设，尚未完成全面查新，也没有实验收益结论。

二、建议系统结构

实际物理仿真状态 → 执行历史编码与交互状态估计 → 更新接触/目标/时序约束 → 扩散生成短段 → 29DoF短窗口投影和可执行性评估 → SuperMimic身体跟踪与双手执行 → 实际物理仿真状态。

规划器读取：文本、最近真实执行的机器人运动、物体位姿与速度、双手实际接触/闭合状态、足支撑和任务阶段。生成结果仍是参考，不直接充当施加给物体的运动。

SuperMimic通过未来参考接口接收更新的身体轨迹。现有独立PPO不读取参考，保留为自主技能基线；仅修改其奖励参考文件并不能改变推理时的决策。

三、三个相互衔接的候选机制

1. 交互状态前缀

前缀来自实际执行，不能使用上一轮计划轨迹冒充。身体历史按本项目既有编码器、坐标约定和统计量重建263D特征；物体与接触状态单独编码或转换为引导条件，不假设当前263D模型已经包含这些信息。

对已建立的抓持，记录手—物体相对位姿。下一段在保持该相对关系的条件下规划；双手搬箱时两只手共享同一箱体位姿，避免各自到达空间点却对箱体施加不相容约束。单有手部“闭合”命令不能证明抓持成立。

对滑落、失接触或不稳定支撑前缀，应标注失败/风险状态并进入恢复分支，不能把任意实际执行片段都称为“已验证稳定前缀”。

2. 根据执行结果修复约束和任务时钟

任务阶段由实际事件推进。没有接触或物体没有随手抬升时，继续修正接近/抓持约束；不因为预设2秒已到，就切换到抬手或倾倒阶段。物体偏移后，目标随实际物体位姿更新；执行落后时，调整未来片段时长和目标速度。

| 技能 | 闭环应具体修正什么 |
|---|---|
| Pick | 没抓住时停留在接近/抓持，重估手相对物体目标；抓持成立后才推进抬起。 |
| Pour | 先保持瓶体抓持，再依据实际瓶体姿态调整倾斜、复正和放下；当前仅能声称瓶体动作，不能声称倒液完成。 |
| 双手搬箱 | 以真实箱体和双手接触共同约束抬升、搬移和放置；单手失接触时调整下一段目标。 |
| 推拉箱 | 按真实箱体位移与接触释放判定推完、释放、重新接触、拉回，不能只检查手腕到点。 |

3. 依据当前执行器能力选择续段

对少量候选短段，结合任务进度误差、已有接触的丢失风险、身体稳定性和片段连接误差选择方案，并允许空间目标/时长一起修正。

可写为候选选择目标：

J(τ)=λg E_task(τ)+λc E_contact(τ)+λb E_balance(τ)+λs E_boundary(τ)+λd E_delay(τ)。

其中任务与接触代价应来自当前控制器实际执行数据训练的预测器，或同一物理场景的短时分支仿真。当前原生SuperMimic世界模型不包含完整手—物体动力学，不能直接用它证明物体抓持、搬运或倾倒可达。它可作为身体可跟踪性信号的一部分。

接触标签、风险预测或自适应重规划各自都有相关先例。本方案需要论证的组合机制是：由执行能力和交互反馈共同决定“下一段约束怎么改、接触怎么保留、阶段什么时候推进”，而非模块数量本身。

四、与现有代码和算力的衔接条件

- 保留原生SuperMimic作为身体控制骨干；双手二值执行、动态物体与接触接口必须补齐，并使用统一资产、关节映射和物理状态约定。当前裸身体跟踪验收不等于该接口已经完成。
- 当前扩散生成使用263D/22点表示，不能把PhyGile的262D表示直接拼入。现有扩散空间提示主要是位置；腕朝向、手命令和接触一致性需要明确的额外接口或投影处理。
- 当前1000步DDPM和整段JAX后优化按离线工作设计，不能直接承诺实时。候选工程路线是短片段、少步采样、缓存文本编码、已执行前缀条件训练，以及短窗口热启动投影；若少步采样质量不足，再讨论蒸馏。所有收益必须实测。
- 一个待测工作点：真实历史0.5–1秒，预测1–2秒，先执行0.5秒，再更新计划；参考20Hz、底层控制50Hz。2Hz重规划只是目标，不是已有性能。要求完整规划链路的P95延迟低于0.5秒，并记录超时率。
- 异步规划结果提交前核对时间戳和当前接触状态。计划过期或与当前抓持不一致时，不直接替换动作缓冲；保留可用缓冲，或由已验证的恢复控制处理。
- 在线首先指固定权重模型根据反馈反复规划。前缀适配、可执行性预测器和控制器微调属于该创新分支的独立训练阶段，不在当前运行任务中进行在线改权重。
- 可复用既有2000参考和已训练先验，再用基线策略额外采集的物理仿真执行片段构建交互前缀数据。不能假定现有训练日志已保存所有所需逐步状态；不要求重做人到机器人重定向或重筛原GRAB/Omni源数据。

五、判断创新是否成立的证据

需要区分三种设置：静态整段参考、仅身体前缀的闭环、加入交互状态与约束/时序修复的闭环。先固定同一低层控制器以隔离规划模块的作用；另行报告闭环分布适配控制器的收益。比较时记录实际推理时间、候选数量与额外仿真预算。

主要指标：真实物体任务成功率、建立/保持接触的比例、滑落率、扰动后恢复率、跌倒率、动作连接处跳变、任务耗时、规划延迟P50/P95及超时率。身体跟踪误差是辅助指标。扰动可包括执行中改变目标物体位置、接触未建立或失接触，以及对象质量/摩擦变化；幅度需在后续正式计划中确定。

低层控制器必须先具备可用的身体跟踪和交互能力。新Pick500参考PPO已完成3000更新，100环境结果为0/100；这份结果要保留并独立诊断，不能预先断言离线生成就是唯一原因，也不能承诺闭环会自动修复低层问题。

建议讨论的主贡献表述：提出面向人形机器人物体操作的物理反馈闭环规划机制，根据实际接触和物体进度修复扩散引导约束与执行时序，并在保持已有交互关系的条件下生成后续运动。

当前不确定性：该组合的相对新颖性、冻结现有扩散模型能否处理执行前缀分布、手—物体执行接口的可用性、完整短窗口链路的延迟，以及真实交互收益。以上需要后续查新与实验验证；尚无排期、训练预算或新实验启动决定。
