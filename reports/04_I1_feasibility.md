# I1 可行性验证：空间条件传递与机器人空间修正

更新：2026-09-29。状态：**组件级初步证据；R3 I1 Gate 未通过。** 本报告仅用于新的通用条件人体运动生成课题。DreamControl Punch 正式基线训练在 GPU 0 原样运行；本实验的只读测量与小规模 IK 试验在 CPU 执行，没有修改该训练。

## 研究问题与证据边界

R3 的 I1 要求提高 robot-space condition success、降低 retargeting drift，同时不明显损害 human-space constraint success、语义和生成成本。首轮只验证其中的空间条件是否从人体生成结果保留到 G1，以及一个**后处理组件**是否能改善 G1 端的目标位置。尚未训练或修改扩散生成器，因此不能把此结果称为完整的 Embodiment-Consistent Constraint-Efficient Generation。

外部目标取自 OmniControl **生成前**给定的 right-foot hint。没有使用生成动作或 G1 轨迹自身推导出的 `kick_pos`/`grab_pos` 作为评分目标。官方坐标映射为源 `(x,y,z)` 到 G1 `(z,x,y)`，官方重定向丢弃源动作第一帧，所以源帧 `t` 对应原始 G1 轨迹帧 `t-1`。评分取受约束时段每帧右脚到目标的三维距离，再按轨迹平均。G1 使用 `right_ankle_roll_link` 作为 SMPL 右脚的代理，二者解剖学位置并不完全相同。计算代码见 `scripts/r3_i1_constraint_transfer_audit.py`，逐条数据与输入 SHA-256 见 `results/r3_i1_constraint_transfer_seed42.json`。

## 固定数据观察

OmniControl seed 42 生成 100 条 Kick，全部保留原始输入 hint。官方重定向阶段产生 64 条原始 G1 轨迹；日志中另外有 4 条因朝向启发式跳过、31 条因“向前移动超过抓取点”启发式跳过、1 条随后因关节限位隔离。这些是**筛选/流程损失**，不能直接等同于 36 条物理不可执行。重定向代码在 Kick 路径里还把 `grab_pos` 后续取自手部关键点，因此该启发式不能替代针对原始脚部目标的有效性检查。

| 固定指标 | 数值 |
| --- | ---: |
| 100 条生成人体动作：平均脚部目标误差 | 0.157 m |
| 其中 64 条可配对动作：人体误差 | 0.128 m |
| 同 64 条：原始 G1 脚踝相对外部世界目标误差 | 0.420 m |
| 同 64 条：逐条移除最佳常量平移偏差后的误差 | 0.116 m |
| 同 64 条：以各自身体根节点为基准的目标误差 | 0.348 m |

原始绝对误差存在明显系统偏移，平均约为 `(−0.174, +0.004, −0.364) m`。移除每条轨迹的常量平移后误差与人体端接近，说明不能把 0.420 m 全部解释为动作姿态丢失。反过来，**不能用事后最佳平移**作为外部绝对位置约束的正式成功率；抬高机器人整体 0.36 m 可能造成漂浮。需要同时保留世界位置和根节点相对位置指标。

## I1 机器人空间一致性组件试验

在相同 64 条中的编号最小 8 条上试验，固定原始人体动作、G1 根轨迹和左腿，只修改右腿六个关节。目标仍为生成前的脚部 hint。对照均运行 80 次 Adam 更新，且使用 G1 URDF 关节限位。代码为 `scripts/r3_i1_robotspace_ik_pilot.py`；以下是**运动学**误差，不是仿真任务成功率。

| 八条探索样本 | 原始误差 | 修正后误差 | 主要问题 |
| --- | ---: | ---: | --- |
| 逐帧独立修正 | 0.419 m | 0.036 m | 逐帧关节变化过大，不能据此声称可执行 |
| 平滑窗口、无改动上限 | 0.419 m | 0.134 m | 部分关节偏离原动作超过 2 rad |
| 平滑窗口、每关节改动限制 1 rad | 0.419 m | 0.156 m | 更保守，仍需检查速度与动力学 |

固定第三种配置后，**未参与参数选择的其余 56 条**得到：

| 未调参的 56 条 | 结果 |
| --- | ---: |
| 平均目标误差：修正前 → 后 | 0.420 → 0.125 m |
| 平均误差相对下降 | 70.3% |
| 目标误差改善的轨迹 | 56 / 56 |
| 平均误差不超过 0.15 m | 41 / 56 |
| 同时满足 0.15 m 且新增逐帧关节变化不超过 0.1 rad | 32 / 56 |
| 新增逐帧关节变化超过 0.1 rad 的轨迹 | 12 / 56 |
| 修正后关节限位违例 | 0 |

`0.1 rad/frame` 仅为本轮质量筛查阈值，**不是**经确认的 G1 速度、扭矩或安全限值。逐条数值与 8/56 划分见 `results/r3_i1_robotspace_ik_smooth_capped_all64.json`、`results/r3_i1_robotspace_ik_smooth_capped_pilot8.json` 和 `results/r3_i1_holdout56_summary.json`。逐帧修正及无上限平滑修正结果也单独保留，防止只报告最好看的目标误差。

## 正在运行的同条件重复采样

为满足 R3 所要求的多种子可行性检查，GPU 1 已完成**同一 100 个空间约束**、采样种子 42/43/44 的官方 OmniControl 推理。包装层只固定提示与 hint 的随机种子，不修改扩散模型、权重或采样算法。`results/r3_i1_fixed_hints_manifest.json` 已逐项核对三组的 hint、文本和长度完全一致，并记录输入 SHA-256。独立队列正在顺序运行官方 G1 重定向，状态在 `artifacts/monitoring/r3_i1_fixed_retarget_queue.state`；随后 `r3_i1_fixed_eval_queue.state` 将顺序完成每种子的条件审计、固定参数 IK 组件试验与三种子汇总。生成完成、模型加载或单个种子重定向成功都不算 I1 Gate 通过。

## 当前结论与下一道门槛

**当前只支持**：在这个 Kick、seed 42 的可配对轨迹集合上，受限的右腿 IK 能改善外部脚部目标的运动学误差。它不是生成器改进，也未证明接触、碰撞、动力学、语义、推理成本或下游 PPO 训练收益。64 条是经过官方启发式筛选后的集合；单动作类别及单种子的证据不能推广到通用动作生成。

因此 I1 判定为 **IN PROGRESS / NO GO YET**。下一步须在固定 100 约束、3 种子上建立 Base、人体约束优选、机器人空间优选和完整 I1 的同预算对照，明确拒绝样本计入分母；补充语义、动作质量、优化步数和耗时，验证修正轨迹在仿真中的动力学执行，并扩展到非 Kick 条件。未完成这些之前，不进入需要 I1 输出作为输入的正式 I2/I3 Gate，也不声称三个创新点已经被验证。
